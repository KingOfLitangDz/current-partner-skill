# 信息录入引导脚本

## 开场白

```
你好，我是现任.skill 知识库创建器。

我会帮你把对象的信息整理成一个本地知识库，
记录 ta 的喜好、你们的时间线、承诺、说话方式——
让你不再忘记那些重要的小事。

整个过程只需要 4 个问题 + 一些素材（可选）。
准备好了吗？
```

## 问题序列

### Q1：称呼/昵称（必填）

```
你平时怎么叫 ta？

不需要真名，平时叫的就行。
比如：宝宝 / 老公 / 亲爱的 / 某某某
```

**验证**：非空即可。生成 slug 规则：中文用拼音，英文用小写，空格替换为下划线。

### Q2：基本信息（可跳过）

```
一句话介绍一下你们的情况？

可以包括：
- 在一起多久了
- ta 做什么工作的
- 在哪个城市
- 怎么认识的

示例：
  "在一起一年了 互联网前端 上海 大学同学"
  "谈了三个月 老师 北京 朋友介绍认识的"
  "刚在一起 同事 深圳"

跳过也行，直接回车。
```

**解析字段**：
- `together_since` / `together_duration`：在一起多久/日期
- `occupation`：职业
- `city`：城市
- `how_met`：认识方式

### Q3：性格画像（可跳过）

```
用一句话描述 ta 的性格？

可以包括：
- MBTI / 星座
- 性格特点
- ta 最让你又爱又恨的地方

示例：
  "INFJ 天蝎座 外冷内热 嘴硬心软 生气不说话但会给我买吃的"
  "ENFP 狮子座 话痨 社牛 占有欲强 但很会照顾人"
  "不知道 MBTI 但是很温柔 有点闷骚 做饭超好吃"

跳过也行。
```

**解析字段**：
- `mbti`：MBTI 类型
- `zodiac`：星座
- `personality`：性格标签列表
- `impression`：主观印象

### Q4：关键纪念日（可跳过）

```
有哪些重要的日子？

可以包括：
- 在一起的日期
- ta 的生日
- 第一次见面
- 任何对你们重要的日子

示例：
  "在一起 2024-06-15 生日 1999-03-20 第一次约会 2024-05-20"
  "520在一起的 ta生日是8月8号"

跳过也没事，之后随时可以补充。
```

**解析字段**：
- `together_since`：在一起日期
- `birthday`：生日
- `first_meet`：第一次见面
- `custom_dates`：其他纪念日

## 汇总确认

```
好的，我整理一下：

  称呼：{name}
  基本信息：{summary}
  性格画像：{personality_summary}
  纪念日：{dates_summary}

这样对吗？确认后开始导入素材（可选）。
```
