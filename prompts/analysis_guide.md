# 原材料分析指南

## 概述

对用户提供的所有原材料（聊天记录、截图、口述）进行结构化分析，提取以下六个维度的信息，存入 RAG 知识库。

---

## 维度一：关系档案（Profile）

从原材料中提取并补充基础信息：

- 饮食偏好：爱吃/不吃什么
- 兴趣爱好：日常做什么
- 生活习惯：作息、洁癖、家务分工
- 消费观：花钱大方还是节俭
- 社交风格：社牛/社恐/选择性社恐
- 家庭背景：与家人的关系
- 未来规划：对关系的期望

---

## 维度二：时间线事件（Timeline）

提取关键时间节点：

| 字段 | 说明 |
|------|------|
| date | 日期（从消息时间戳/口述推断） |
| event | 事件名称（简洁） |
| detail | 具体描述 |
| emotion | 情感色彩（positive/neutral/negative） |
| tags | 标签（first_meet/anniversary/fight/trip/milestone） |

**重点提取**：
- 第一次：第一次见面、第一次约会、第一次吵架、第一次旅行
- 转折点：确定关系、见家长、同居、重大分歧
- 日常高光：特别开心/感动的瞬间

---

## 维度三：承诺追踪（Promises）

提取双方做出的承诺：

| 字段 | 说明 |
|------|------|
| who | ta / me |
| content | 承诺内容 |
| date | 承诺日期 |
| deadline | 截止日期（如有） |
| status | pending / completed / broken / expired |
| context | 在什么场景下承诺的 |

**提取信号词**：
- "我保证" / "我答应你" / "说好了" / "下次一定"
- "你说过" / "你答应过" / "你保证的"
- "我们说好的" / "约定"

---

## 维度四：语言模式（Language Patterns）

### 4.1 口头禅（catchphrase）
- 高频使用的词/短语
- 标志性表达方式
- 撒娇/生气/开心时的特定用语

### 4.2 说话风格（texting_style）
- 消息长度：短句连发 / 长段落
- 标点习惯：句号/省略号/感叹号/波浪号
- emoji 偏好：常用哪些 / 从不用
- 语气词：嗯/哦/噢/哈哈/嘿嘿
- 称呼方式：怎么叫用户
- 打字特征：错别字/缩写/方言

### 4.3 期望回复方式（expected_reply）
从对话模式中推断 ta 期望怎样的回复：

| 字段 | 说明 |
|------|------|
| scenario | 场景描述（ta说了什么/做了什么） |
| good_reply | 好的回复方式 |
| bad_reply | 不好的回复方式 |
| note | 补充说明（为什么这样回复更好） |

**提取信号**：
- ta 发了某类消息后，用户的某种回复让 ta 开心（从后续对话推断）
- ta 发了某类消息后，用户的某种回复让 ta 不开心或引发争吵
- 用户明确口述的 "ta喜欢我这样回"

---

## 维度五：情感模式（Emotional Patterns）

| 字段 | 说明 |
|------|------|
| emotion | angry / sad / happy / jealous / clingy / cold |
| triggers | 什么会触发这个情绪 |
| signs | 表现特征（消息风格变化、行为变化） |
| best_response | 最佳应对方式 |
| worst_response | 最差应对方式（绝对不要做的） |
| cool_down_time | 冷静期（如适用） |

**重点关注**：
- 争吵时的对话模式（从聊天记录中提取）
- 冷战的持续时间和打破方式
- ta 开心时的表现（对比分析）

---

## 维度六：Inside Jokes & 共同记忆

- 只有两个人懂的梗
- 共同的暗号/代称
- 常去的地方
- 共同喜欢的歌/电影/食物
- 有特殊意义的物品

---

## 分析原则

1. **客观提取，不虚构**：所有信息必须基于原材料或用户口述
2. **标注信息来源**：每条记录标注来自哪个素材
3. **不足标注**：信息不足的维度标注 `[待补充]`
4. **冲突处理**：原材料之间有矛盾时，标注冲突让用户确认
5. **持续迭代**：每次更新只做增量，不覆盖已有记录
